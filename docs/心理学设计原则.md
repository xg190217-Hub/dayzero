# DayZero 心理学设计原则（调研沉淀 · 2026-09）

> 来源：行为心理学 / 色彩科学 / 营销心理学三份专项调研（实证文献为主）。
> 用途：后续所有迭代与审核对照此文档；新项目直接复用。
> 证据强度：强=多项 RCT/meta；中=单一大样本或一致性观察；弱=共识/惯例。

## 一、行为心理学（已在产品中落地的部分）

| 原则 | 证据 | DayZero 落地 |
|---|---|---|
| 自我监控必须闭环到反馈 | 强（d=.40；+反馈 d=.42 vs 单监控 d=.25） | 打卡后 SnackBar 显示「本周渴求均值 vs 上周」（insightBetter/Worse） |
| if-then 实施意向 | 强（d=.65，需具体情境线索） | 「我的应对计划」编辑器（情境下拉+行动文本），SOS 页关键时刻展示 |
| 失误≠复发：归因决定滑向失控 | 中强（破堤效应） | 复吸流程改为：记录失误（诱因+备注）→「记录并继续」或「记录并重计」；历史永不归零 |
| 断链时给修复路径，不羞辱 | 中（INSEAD；Duolingo freeze） | 同上；文案无全或无表述 |
| 渴求是限时波浪（3–30 分钟） | 中（临床共识） | SOS 文案「几分钟达峰然后消退」；**不要写"90 秒必过"** |
| 接纳（冲浪）不劣于分心，高危人群更优 | 中 | 待做：SOS 增加"观察-冲浪"引导分支 |
| 习惯养成 ~66 天，单次遗漏无害 | 中强 | 里程碑含 30/90/180/365；**不要宣传"21 天"** |
| 金钱激励强（RR 1.52，与金额无关） | 强 | 省钱统计；可选押金模式参与率仅 10-14%（暂不做） |
| 承诺装置温和可选、保护性框架 | 中 | 每日提醒默认开但可一键关；无惩罚机制 |
| 游戏化：掌握导向，禁排行榜/掉级 | 中 | 徽章无排名；待做：徽章按用户进度自适应 |
| 自主性支持（SDT） | 中强 | 重启日期/提醒时间/主题字体全部用户自选 |
| 通知：频率>时机不显著，负担有上限 | 中 | 每日 1 条；用户可选整点 |
| 身份认同文案 | 中 | 待做：「你已经是非吸烟者第 N 天」类文案 |

## 二、色彩科学（已落地的部分）

| 原则 | 证据 | DayZero 落地 |
|---|---|---|
| 唤醒由饱和度/明度决定，色相次要 | 强 | 主色 #146A4F 低明度；大面积去饱和方向 |
| 红色=威胁/回避线索，仅限小面积警示 | 强（但有反证） | SOS 用暖琥珀而非警报红；红色仅用于删除按钮 |
| 绿色减压=自然内容而非绿色本身 | 中（纠偏） | 绿色用于品牌联想，不宣传"绿色降焦虑" |
| 深色模式用深灰+提亮主色，非纯黑 | 惯例+机制 | 背景 #101714；fromSeed 自动提亮深色 primary |
| 文字对比 WCAG AA 4.5:1 / 大文本 3:1 | 标准 | 全组件实测：SOS 按钮浅 6.9:1/深 8.4:1；徽章 10.7:1；自定义色相动态前景色 |
| 文字色板按亮度配对 | — | 8 色板每色配深色变体 |
| 60-30-10 比例；避免情绪线索冲突 | 惯例 | 强调色从 colorScheme 派生，主题切换全联动 |
| 文化符号：中文忌绿帽/纯白，日本喜低饱和 | 强 | 暖白 #F6F4EE；无绿帽元素；紫=高端（欧美） |

## 三、营销心理学（已落地的部分）

| 原则 | 证据 | DayZero 落地 |
|---|---|---|
| 获取期用收益框架，禁用损失框架 | 强（222,385 人实验） | 付费墙无"别让努力白费"类文案 |
| 承诺一致性：手写理由最强 | 强 | 付费墙标题引用用户手写理由 |
| 用户自己的数字 > 功能清单 | 逻辑强 | 付费墙显示「已省 ¥XXX」；年付显示绝对节省「省 ¥272」 |
| 百分比强迫心算，绝对金额更优 | B | "50% off"徽章保留但叠加绝对金额 |
| 预置进度 | 强（34% vs 19%） | 引导页显示「第 2/5 步」 |
| 试用 ≥ 价值达成时间 | B（冲突，需自测） | 年付 7 天试用（ASC 配置），上线后 A/B 14 天 |
| 试用显式披露、禁 toggle | 强制（Apple 2026-01） | 年付卡显式"7 天免费试用"；无开关 |
| 周付档是合规与声誉风险 | B | 保留但已归档；考虑上线后移除（A/B） |
| 终身价 = 年费 3.7×（锚定+防蚕食） | B | ¥998（原 ¥598=2.2× 起不到锚定） |
| 用户自己的数据永不收费 | 品类口碑铁律 | 30 天统计视图已解锁；自救工具全免费 |
| 关闭按钮必须可见 | 强制 | 付费墙 AppBar 返回按钮保留 |
| 取消流程对称 | 强制+赚钱（auto-cancel +23%） | 待做：取消引导页（暂停/换档），Apple 侧由系统处理 |

## 四、红线（永远不做）

1. 损失框架做获取；断签羞辱文案；"21 天习惯"宣传
2. 红色用于复发/失败主视觉；纯白大面积；高饱和色做大面积
3. 虚假倒计时/划线价/人气数字；预选付费档；隐藏关闭按钮
4. 在渴求/复发/断签时刻弹付费墙
5. 排行榜、掉等级、社交比较（低自我效能者伤害明确）
