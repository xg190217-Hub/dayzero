# DayZero 上架清单（提审行动手册）

> 目标：**一次过审**。前两个项目踩过的坑（8 次"无法添加以供审核"、2.1 被拒、3.1.2c EULA 被拒）全部在此清单里提前焊死。
> 每一步的字段值都写在 `store/STORE-METADATA.md`，照着抄即可。

---

## 第 0 步：代码托管（一次性，约 30 分钟）

1. 在 GitHub 创建公开仓库 `dayzero`（主页仓库 `dayzero` 的 gh-pages 同时承载隐私政策/条款/支持页）
2. 本地推送代码（VPN 开 TUN 模式；push 失败就用 GitHub 网页上传文件，对新手最稳）
3. **GitHub Pages 托管**（仓库 Settings → Pages → 从 `gh-pages` 分支发布）：
   - `store/privacy-policy.md` → 上传为 `privacy.md`，URL：`https://xg190217-hub.github.io/dayzero/privacy`
   - `store/terms.md` → 上传为 `terms.md`，URL：`https://xg190217-hub.github.io/dayzero/terms`
   - `store/support.md` → 上传为 `support.md`，URL：`https://xg190217-hub.github.io/dayzero/support`
   - 上传后 **curl 三个 URL 验证可达**，搜索确认没有 `[SUPPORT EMAIL]` 之类占位符
   - ⚠️ App 内设置页/付费墙链接已写死这三个 URL——必须先托管成功再提审

## 第 1 步：App Store Connect 建 App（约 30 分钟）

1. App Store Connect → 「我的 App」→ 新建 App
   - 名称：`DayZero: Quit Drinking Tracker`（若重名被占，用 store/STORE-METADATA.md 的备用名）
   - Bundle ID：`io.dayzero.app`（先在「证书、标识符和描述文件」里注册此 Bundle ID）
   - SKU：`dayzero`
2. App 信息页：
   - 分类：Health & Fitness（主）/ Lifestyle（次）
   - 版权：`© 2026 DayZero`
   - 年龄分级问卷：按 STORE-METADATA.md 答案 → 结果 12+
   - 内容版权问卷：**「不包含第三方内容」**（图标/音效全部程序化原创合成）
   - 许可协议：留空（用 Apple 标准 EULA，描述里已带链接）→ 或填自定义 EULA
3. 隐私（营养标签）：**Data Not Collected**（三类全选否——App 无账号、无 SDK、无网络请求）
4. **支持网址**：`https://xg190217-hub.github.io/dayzero/support`（必填！上次 1.5 被拒的根因）
5. **隐私政策网址**：`https://xg190217-hub.github.io/dayzero/privacy`
6. 价格与供应范围：定价「免费」；**先取消勾选中国大陆**（等 ICP 豁免批复后再开）
7. 付费 App 协议：确认状态 Active（前两个项目已激活，若显示待更新就重新同意）

## 第 3 步：真机录屏（提审前一天，5 分钟）

- iPhone 控制中心 → 屏幕录制
- **从点 App 图标开始**，全流程 2 分钟：
  引导选酒精 → 开始旅程 → 首页计数器 → 打卡（选情绪+保存）→ 渴求急救（呼吸圈）→ 统计页 → 里程碑 → 设置 → 付费墙（4 档价格滚动一遍）→ 恢复购买 → 返回
- 上传到百度网盘/阿里云盘 → 生成**永久有效**的分享链接（审核备注第 1 点要用）

## 第 4 步：Codemagic 构建（约 30 分钟）

1. codemagic.yaml 已在仓库里（workflow `dayzero-ios`，bundle id 已配好）
2. Codemagic 后台 → Teams → Environment variables → 新建变量组 **`dayzero-app`**：
   - `APP_STORE_CONNECT_ISSUER_ID`（Secret ✓）
   - `APP_STORE_CONNECT_KEY_ID`（Secret ✓）
   - `APP_STORE_CONNECT_API_KEY`（.p8 内容，Secret ✓）
   - `CERTIFICATE_PRIVATE_KEY`（复用前两个项目的那把私钥！存 Secret ✓——不要重新生成，避免撞 3 张证书上限）
3. 触发构建 → 自动上传 TestFlight
4. **TestFlight 真机安装 → 全流程点一遍**（锁定状态、控件联动、付费墙、恢复购买、删除账号不适用——无账号）

- 描述：见 STORE-METADATA.md（英文），其余语言见 STORE-LOCALIZATIONS.md
- 截图：`test/screenshots/6.9_en/` 的 6 张（1320×2868）传到 6.9" 槽位；中文区追加 `6.9_zh/` 套

## 第 6 步：提交（5 分钟）

1. 「App 审核信息」：
   - 联系信息：电话带 `+86` 国家码
   - 备注：粘贴 STORE-METADATA.md 的**六段式备注模板**（录屏链接放第 1 点）
2. 点 **Add for Review** → 再点 **Submit for Review**（两步！第二步才是真提交）
3. 提交后 24–48 小时留意邮件；收到信息请求**当天回复**

## 被拒/2.1 标准动作（前两个项目的血泪总结）

1. 收到 2.1：**当天**回复六段式信息（录屏链接已有，成本为零）
2. 被拒：**立刻升版本号 1.0.1**（旧列车已关闭，别在旧号上重建）+ 带完整备注重新提交
3. App 专属怪状（TestFlight 装不了等）：先对照 Petory/摇骰子是否正常 → 定位账号级 vs App 级 → 查错误码 → 果断开工单（记工单号）

## 中国大陆 ICP 备案（可选路径，提审后并行）

App 完全离线、仅用 StoreKit IAP → 可申请豁免（约 3 天）：
1. developer.apple.com/cn/ → 底部「联系我们」→ 分发 → 有关分发的其它疑问
2. 填表说明：应用 100% 离线运行、无服务器、无联网功能，仅使用 Apple StoreKit 进行应用内购买；应用 Apple ID 填 DayZero 的 App ID
3. 苹果一般次日回信要求书面声明 → 回复后约 3 天通过
4. 豁免批复后再在「价格与供应范围」勾选中国大陆，并上传中文截图套
