# DayZero 运营作战手册（上线后 0-90 天）

> 依据：变现调研报告（ASO 是零成本最高杠杆；本地化 +26% 收入；硬付费墙 D35 转化 10.7%）。
> 原则：零埋点不妥协（隐私卖点），一切运营数据看 **App Store Connect 的匿名聚合分析**。

## 上线当天

- [ ] App Store Connect → App 分析：确认「来源」里自然搜索开始有数据
- [ ] 检查 IAP 产品状态全部 Ready to Submit ✓（提审时已配）
- [ ] 设置里 `kAppStoreId` 填上真实 App ID（启用第 5 次打卡的评分引导），发 1.0.1
- [ ] 把评分引导的版本随 1.0.1 一起提（新构建直接带 App ID）

## 第 1-2 周：止血

- [ ] **48 小时内回复所有评论**（转化率直接杠杆，尤其 1-3 星）
- [ ] ASC 分析看崩溃：有崩溃立即修（2.1 被拒风险）
- [ ] 首次小额 Apple Search Ads 测试：预算 **$100-200**，只买精确匹配词
  `quit drinking` / `sober app` / `days since`，看 CPI 与转化
- [ ] 截图 A/B：用 ASC 的 Product Page Optimization 测图标与首图（图标测试实测 +5% 转化）

## 第 3-6 周：数据驱动调价

- [ ] 看 ASC 分析：付费墙到达率 × 购买转化
- [ ] 若首月转化率 **>8% → 涨价 20-30%**（预期净收入 +5-15%）
- [ ] 若转化率 <1% → 降价或调免费层边界
- [ ] 年付占比 <30% 时：加大年付折扣展示（当前 50% off）

## 第 6-12 周：放大

- [ ] **每 2-4 周发一个有意义更新**（获 Apple 编辑推荐的唯一可靠方式；三个月不更新的 App 永不获推）
  - 1.0.x 路线图：主屏小组件（锁屏天数）、Apple Watch 伴生、更多恢复事实
- [ ] ASO 关键词月度精修：用 FoxData/Appfigures 免费额度看自己排名
- [ ] 日语/德语/中文区截图本地化（test/screenshots/6.9_zh 已就绪）
- [ ] 考虑 UGC 创作者（TikTok 戒断内容创作者合作，$10-20/条 + 绩效）
- [ ] 12 周复盘：按数据决定第二个 App（组合策略是被验证的破局路径，管线全部复用）

## 底线预期（如实提醒）

- 新 App 第一年模态结果 $0-100/月；$1,000/月 = 前 17%
- 达到 $1K/月的中位数用时 58 天——**要么快，要么慢很久**
- 收入没起色的最大可能是 ASO 排名爬升慢，不是产品差；保持更新节奏等爬坡
